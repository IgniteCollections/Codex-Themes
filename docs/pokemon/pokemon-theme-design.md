# 宝可梦主题设计文档

日期： 2026-07-18（素材策略更新：私人使用，官方 sprite 直接入库）

本文是宝可梦 Codex 主题的设计总纲：场景体系、宝可梦选角逻辑、配色推导、素材使用方式。开发机制见 [theme-development-guide.md](theme-development-guide.md)，需求基线见 [requirements.md](requirements.md)。

## 1. 设计概念

把 Codex 终端变成宝可梦图鉴世界：每个「场景」是游戏里的一个栖息地，用户切换场景 = 走到新的地方，遇到不同的宝可梦，终端的整体视觉（配色、提示符、横幅、文案）随之换肤。

设计锚点是 **GBA 世代（Gen III，红蓝宝/火红叶绿/绿宝石）的像素质感**：64×64 sprite、颗粒感、暖饱和配色。

## 2. 场景 × 宝可梦选角逻辑

### 2.1 选角原则

每个场景选 4 只宝可梦，按以下角色搭配（不是随便挑同属性）：

| 角色 | 作用 | 例子（草原） |
|---|---|---|
| **招牌（Mascot）** | 场景门面，出现在横幅/英雄区，知名度最高 | 妙蛙种子 |
| **氛围（Ambient）** | 强化环境感，图鉴描述与场景强绑定 | 走路草 |
| **路人（Common）** | 道路上最常见的那只，增加"真的在草丛里"的感觉 | 绿毛虫、波波 |

选角规则：
- 属性/栖息地必须与场景强匹配（官方图鉴栖息地分类）
- 至少 1 只 Gen I（情怀锚点），尽量跨世代但不超出广为人知范围
- 招牌必须是高辨识度角色（路人看到就知道是哪个场景）
- 雪原/发电厂的招牌选电/冰系里最有「职业感」的（电击兽=电厂工人、冰伊布=雪原精灵）

### 2.2 六场景阵容与选角理由

| 场景 | 招牌 | 其余 | 选角理由 |
|---|---|---|---|
| 草原 | 妙蛙种子 #1 | 走路草 #43、绿毛虫 #10、波波 #16 | 1 号道路标准遭遇表；妙蛙种子是草系第一门面 |
| 海洋 | 暴鲤龙 #130 | 拉普拉斯 #131、玛瑙水母 #72、鲤鱼王 #129 | 暴鲤龙=海上霸主；鲤鱼王→暴鲤龙构成"水面下藏着什么"的叙事；玛瑙水母是冲浪最烦也最经典的遭遇 |
| 洞穴 | 大岩蛇 #95 | 超音蝠 #41、小拳石 #74、地鼠 #50 | 大岩蛇=洞穴探索的压迫感天花板；超音蝠+小拳石是月见山标配 |
| 岩浆 | 小火龙 #4 | 鸭嘴火兽 #126、熔岩虫 #218、煤炭龟 #324 | 小火龙尾巴火焰=火山光源，招牌度满分；熔岩虫/煤炭龟是火山生态 |
| 雪原 | 冰伊布 #471 | 急冻鸟 #144、海豹球 #363、雪童子 #361 | 冰伊布=雪原最美的存在；急冻鸟提供传说级稀有遭遇的仪式感 |
| 发电厂 | 皮卡丘 #25 | 小磁怪 #81、电击兽 #125、雷电球 #100 | 皮卡丘是全系列第一招牌，无人发电厂是它在红蓝里的经典栖息地；雷电球伪装成精灵球=场景彩蛋 |

### 2.3 场景叙事文案（图鉴口吻）

每场景一句遭遇文案 + 一段设计说明，示例：

- 草原：「野生的 妙蛙种子 出现了！微风带来了青草的香气。」
- 岩浆：「野生的 小火龙 出现了！尾巴的火焰把四周照得通亮。」
- 发电厂：「野生的 皮卡丘 出现了！废弃的机器间闪过一道电光。」

完整 24 只的图鉴 ID 对照表见 [pokemon-assets.md](pokemon-assets.md#附录本项目-24-只宝可梦的图鉴-id)。

## 3. 场景配色体系

### 3.1 每场景 5 主色（需求基线，不可更改）

见 [requirements.md](requirements.md#必须的-6-个场景--匹配宝可梦不可更改可扩展)。

### 3.2 从 5 主色推导完整调色板

每场景由 5 主色推导三类产物色板，推导规则统一：

**ANSI 16 色（终端模拟器/展示用）**

| ANSI 槽位 | 语义 | 推导规则 |
|---|---|---|
| black / bright black | 背景、注释 | 文字色（最深色） / 其加亮 20% |
| red / bright red | 错误、diff 删除 | 场景"危险色"（岩浆=熔岩红，草原=暖橙红，雪原=暗珊瑚） |
| green / bright green | 成功、diff 新增 | 场景主色（草原=嫩绿，海洋=浪青，岩浆=硫化黄绿） |
| yellow / bright yellow | 警告 | 场景点缀暖色（阳光黄/余烬黄/电光黄…） |
| blue / bright blue | 信息、链接 | 场景冷色（海洋=深海蓝，洞穴=暗紫，雪原=极光蓝…） |
| magenta / bright magenta | 次要强调 | 与主色相距 120° 的补色 |
| cyan / bright cyan | 次要信息 | 主色向青偏移 |
| white / bright white | 正文、高亮正文 | 奶白/泡沫白/冰白（最浅色） |

**语义映射（所有场景统一）**：红=错误，绿=成功，黄=警告，蓝=信息——语义不随场景改变，只替换色相，保证任何场景下终端输出可预期。

**tmTheme 语法色**：keyword=主色、string=第二色、comment=bright black、number=点缀色、diff 增/删=语义绿/红。具体映射表按 [theme-development-guide.md](theme-development-guide.md#必备-scope-清单codex-场景) 执行。

## 4. 宝可梦素材使用设计（私人使用，官方 sprite 直接入库）

> 版权说明：仅限个人私人用途，素材不二次分发。仓库 public 可见性带来的风险由所有者自行承担。

### 4.1 素材来源与取舍

| 来源 | 用途 | 取舍 |
|---|---|---|
| **PokeAPI/sprites** Gen III `versions/generation-iii/` | 网站宝可梦图像主力（64×64 像素 sprite） | ✅ 直接下载入库 `Pokemon/app/public/pokemon/` |
| PokeAPI/sprites `other/official-artwork/` | 场景详情页大立绘（475×475） | ✅ 招牌宝可梦可选使用 |
| **NightCatSama/pokedex** `pokemon.json` | 24 只的中文名、图鉴描述（flavor 文案底稿） | ✅ 摘录需要的字段入库为 scenes 数据 |
| HybridShivam/Pokemon | — | ❌ 不需要（立绘已有 PokeAPI 来源） |

### 4.2 入库清单与命名

24 只宝可梦 × 每只 1 张 Gen III sprite（绿宝石版优先，动画感最强）：

```
Pokemon/app/public/pokemon/
  001.png   # 妙蛙种子（Gen III emerald 64x64）
  004.png   # 小火龙
  ...24 个文件，按图鉴 ID 三位零填充命名
  artwork/  # 可选：6 张招牌的官方立绘
    001.png 004.png 025.png ...
```

下载来源 URL 模式：
```
https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/versions/generation-iii/emerald/{id}.png
https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/official-artwork/{id}.png
```

### 4.3 页面中的使用方式

| 位置 | 素材 | 呈现 |
|---|---|---|
| 场景图鉴页档案卡 | Gen III sprite | `image-rendering: pixelated` 放大到 128px，保留像素颗粒 |
| 场景卡片（首页） | Gen III sprite | 招牌 1 只 + 其余以剪影/小图排列 |
| 英雄区终端演示 | 保留字符画 | sprite 不进终端模拟窗口（终端里没有图） |
| 宝可梦芯片/标签 | sprite 缩略 24px + 中文名 + 属性 | 图鉴芯片样式 |
| 场景切换动效 | 招牌 sprite | 白闪 + sprite 弹出（遭遇战仪式感） |

展示规则：
- 一律加 `image-rendering: pixelated`，禁止平滑缩放破坏像素感
- 中文名、属性、图鉴描述来自数据文件（源自 pokedex 摘录），不运行时请求外部 API
- 保留现有的自绘字符画作为终端内装饰（终端上下文），sprite 用于网页上下文——两者并存不矛盾

## 5. 场景视觉要素清单（每场景必须定稿）

- [ ] 5 主色 + 推导出的 ANSI 16 色
- [ ] tmTheme 语法色映射
- [ ] 提示符符号（❀ ≈ ◆ ▲ ❄ ⚡）
- [ ] 招牌宝可梦 sprite + 字符画横幅
- [ ] 遭遇文案 + 设计说明
- [ ] 状态栏配色（前景/背景/强调）
- [ ] 专属场景插画（现有 scene-*.png 保持，或 sprite 组合场景）

## 6. 落地顺序

见 [roadmap.md](roadmap.md)。素材相关改动并入任务 2（数据建模）与任务 4（图鉴页补全）：先下载 sprite 入库 + 摘录中文数据，再改页面。
