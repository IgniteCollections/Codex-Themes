## 产品定义

为终端 AI 编程助手「CODEX」设计的一套宝可梦主题皮肤系统。核心玩法：用户选择不同的「场景」，整个终端 UI（配色、横幅、提示符、状态栏、ASCII 装饰）随之切换，每个场景都有与之匹配的宝可梦「出没」。

## 每个场景必须包含的设计要素

- ANSI 16 色终端调色板（normal + bright 两组）
- CODEX 终端界面元素配色：背景、前景、提示符（prompt)、命令输出、成功/警告/错误状态色、状态栏、边框
- 专属 ASCII / 像素风横幅与宝可梦装饰（字符画或像素块，不用真实图片）
- 场景专属提示符符号：草原 ❀、海洋 ≈、洞穴 ◆、岩浆 ▲、雪原 ❄、发电厂 ⚡
- 一句场景 flavor 文案（图鉴口吻），如「野生的 妙蛙种子 出现了！」

## 网站内容要求

- 首页：英雄区 + 可交互 CODEX 终端模拟窗口（用户提问、codex 回复、diff 输出、状态栏），6 场景切换器，切换时整页换肤 + 平滑过渡动画
- 场景图鉴页：6 个场景完整档案卡（调色板色块、宝可梦列表、终端预览、设计说明）
- 配置/安装页：每个场景的可复制配置代码块（config.toml 片段 + ANSI 调色板 JSON），一键复制
- 整体风格：深色基调 + 像素/复古游戏质感与玻璃质感结合，图鉴仪式感
- 全站中文文案，代码与命令保持英文

## 范围扩展（2026-07-18 新增）

在展示网站之外，交付**真实可用的 Codex 主题产物**：

- 每个场景一个 `.tmTheme` 文件（Codex TUI 官方支持的自定义主题格式，见 [codex-official-theming.md](codex-official-theming.md)），放入仓库 `Pokemon/themes/`，用户复制到 `~/.codex/themes/` 即可用 `/theme` 选择
- 安装页提供真实可用的安装命令与 config.toml 片段（`tui.theme = "pokemon-<scene>"`）
- 素材调研结论与版权风险见 [pokemon-assets.md](pokemon-assets.md)
