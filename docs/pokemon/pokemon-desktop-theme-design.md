# 宝可梦桌面主题设计文档（Codex 桌面 App 主线）

日期： 2026-07-18（阵容 v3：御三家进化链为主 + 新增宇宙场景）

本文是宝可梦主题在 **Codex 桌面 App** 上的设计定稿：场景阵容、桌面字段映射、视觉规则。开发标准见 [desktop-theme-development-guide.md](desktop-theme-development-guide.md)；人气数据见 [pokemon-theme-design.md](pokemon-theme-design.md) §2。

## 1. 选角规则（v3）

1. **常规位以御三家为主，囊括所有进化型**：每个场景的常规阵容优先选该属性御三家的**完整进化链**（初始→一段→最终）。进化链让图鉴页有"收集成长"的叙事感，也是御三家人气最高效的使用方式
2. **神兽/幻兽 3 只**：与栖息地强绑定，按稀有度梯度排列（常见传说 → 封面神 → 幻兽）
3. 无法被御三家覆盖的场景保留原人气阵容作为"原住民"补充
4. 招牌（Mascot）= 场景内人气最高者

## 3. 桌面字段映射（每场景）

由 scenes.ts 的 ui 色板派生，规则统一（generate-desktop-themes.py 实现）：

| codex-theme-v1 字段 | 取值来源 |
|---|---|
| `codeThemeId` | `"codex"` |
| `variant` | `"dark"`（7 场景全部深色底） |
| `theme.accent` | `ui.prompt` |
| `theme.surface` | `ui.bg` |
| `theme.ink` | `ui.fg` |
| `theme.contrast` | 按场景明度差 50–64 |
| `theme.opaqueWindows` | `true` |
| `theme.fonts` | `{ "code": null, "ui": null }` |
| `semanticColors.diffAdded` | `ui.diff-add-fg` |
| `semanticColors.diffRemoved` | `ui.diff-del-fg` |
| `semanticColors.skill` | `ui.accent-2` |

宇宙场景桌面主题派生预览：accent #FFD700（流星金）、surface #0B0B1E（深空黑）、ink #E8E8F8（星尘白）、diffAdded #00A86B（裂空绿）、diffRemoved #E05A7A（陨石红）、skill #6C5CE7（臭氧紫）、contrast 62。

## 4. 桌面 App 视觉呈现设计

桌面 App 不能用自定义图片做 UI 背景，宝可梦存在感通过：主题命名（`Pokemon · 草原` 等）、展示站图鉴页档案卡（同份色板渲染）、安装页桌面段的场景卡（招牌 sprite + 阵容 sprite 列 + 导入字符串）。

图鉴页新增"进化链"展示组件：御三家链以 `初始 → 一段 → 最终` 横向排列，sprite 从小到大（24px → 48px → 72px），体现成长感。

## 5. 备忘

- **巨金怪（合金十字）#376**：超能力+钢，总榜高人气，但官方栖息地是山地/洞窟。已列入洞穴场景神兽池扩展候选（第 4 只神兽），不进宇宙阵容——保留"栖息地强绑定"原则
- 宇宙场景的基拉祈同时出现在"常规补充"和"神兽池"：它是宇宙主题叙事核心（许愿星），两处的角色不同（常规=可见遭遇，神兽池=稀有槽位），实现时任选一处展示，建议放神兽池
