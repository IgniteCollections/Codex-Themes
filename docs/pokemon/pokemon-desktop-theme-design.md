# 宝可梦桌面主题设计文档（Codex 桌面 App 主线）

日期： 2026-07-18

本文是宝可梦主题在 **Codex 桌面 App** 上的设计定稿：场景阵容（神兽 + 人气宝可梦）、桌面字段映射、视觉规则。开发标准见 [desktop-theme-development-guide.md](desktop-theme-development-guide.md)；场景选角的人气数据与原则见 [pokemon-theme-design.md](pokemon-theme-design.md) §2（两份文档共享同一套选角体系，本文是桌面交付的具体化）。

## 1. 场景阵容（每场景 6 只：3 神兽/幻兽 + 3 人气常规）

规则：
- **神兽/幻兽 3 只**：与场景栖息地强绑定，按"稀有度梯度"排列（常见传说 → 封面神 → 幻兽），满足"每个环境都有几只神兽"的要求

## 2. 桌面字段映射（每场景）

由 scenes.ts 的 ui 色板派生，规则统一（generate-desktop-themes.py 实现）：

| codex-theme-v1 字段 | 取值来源 | 说明 |
|---|---|---|
| `codeThemeId` | `"codex"` | 内置默认语法主题，最稳 |
| `variant` | `"dark"` | 6 场景全部为深色底（雪原虽是浅色系场景，其终端底色 #0A1622 仍是深色） |
| `theme.accent` | `ui.prompt` | 场景主强调色（嫩绿/浪青/矿晶青/炽橙/浅青/电光黄） |
| `theme.surface` | `ui.bg` | 场景终端底色 |
| `theme.ink` | `ui.fg` | 场景正文色 |
| `theme.contrast` | 每场景按明度差设定（50–64） | 高对比场景（雪原/发电厂）取高值 |
| `theme.opaqueWindows` | `true` | 像素风需要实底 |
| `theme.fonts` | `{ "code": null, "ui": null }` | 默认字体，不强制 |
| `semanticColors.diffAdded` | `ui.diff-add-fg` | 场景语义绿 |
| `semanticColors.diffRemoved` | `ui.diff-del-fg` | 场景语义红 |
| `semanticColors.skill` | `ui.accent-2` | 场景次强调色 |

## 3. 桌面 App 视觉呈现设计

桌面 App 不能用自定义图片做 UI 背景（官方字段只有颜色/字体），宝可梦的存在感通过以下方式承载：

| 位置 | 呈现 |
|---|---|
| 主题命名 | 导入字符串的"主题"在 Appearance 列表里显示为场景名（`Pokemon · 草原` 等，以导入时命名为准） |
| 展示站桌面段 | 安装页「桌面客户端」区：每场景一张卡——招牌 sprite + 神兽池 sprite 列 + 可复制导入字符串 + 导入步骤 |
| 精灵图鉴展示 | 展示站图鉴页现有档案卡即桌面主题的"预览图"（同一份色板渲染） |
| 字体建议 | 像素风玩家可选配等宽字体（fonts 字段默认 null，文档中给出可选建议如 JetBrains Mono / 更纱黑体） |
